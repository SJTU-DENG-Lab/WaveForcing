01 · The bottleneck

A sequential algorithm leaves parallel hardware waiting.

Rolling Forcing generates a long video chunk by chunk. Each chunk normally walks through every denoising step before the next chunk can advance. More GPUs do not help if they all wait on the same chain.

03 · Layout

Paged writes remove the assembly wall.

Each producer writes directly into its fixed slot in the consumer's contiguous attention buffer. Attention reads the prefix in place—no per-layer reconstruction.

torch.cat: 18.49 → 4.08 ms · recommended
Why this is not one linear stack

FP8 KV is a byte-reduction experiment; current paged transport is BF16 and does not yet support FP8 one-sided slots. The best measured route is SageAttention + BF16 paged direct-write: 431.9 ms/tick on the 14B setup.

04 · VAE without bubbles

Overlap work across GPUs,
not on the same SMs.

05 · Throughput

Pipeline depth becomes throughput.

Once filled, latency no longer scales with the number of denoising steps in the usual way: every tick retires another chunk.

Quality note

The architecture is exact with the time-balanced VAE split. SageAttention is near-lossless per step; practical long-video quality is primarily bounded by the current Wan2.1 1.3B rolling-forcing checkpoint.
